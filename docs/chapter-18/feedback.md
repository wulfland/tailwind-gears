# Customer feedback: constructed sample

Twenty fictional comments about the Tailwind Gears catalog, written for the Chapter 18 activity *Synthesizing customer feedback into hypotheses with an assistant and checking every claim*. They are not real customer messages and must not be presented as evidence about any product. Each comment has an identifier so that a hypothesis can cite the comments it rests on.

Some comments describe the sample's real behavior and some do not. For example, the search is case-sensitive (F01, F10), there is no category filter (F02), the sold-out Loop Lock is shown with a badge (F04), and the search does not clear when the sort changes (F15 is wrong about the sample). Checking a hypothesis against the comments it cites, and the comments against the application, is the point of the activity.
